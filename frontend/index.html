SessionalHub

Smart Assessment, Simplified Learning.

SessionalHub is a web-based platform designed to automate question paper generation, answer sheet evaluation, syllabus management, and student performance tracking using AI and modern web technologies.

About The Project

The system helps teachers generate balanced question papers, evaluate student answer sheets, upload notes and PYQs, and manage syllabus data. Students can generate practice papers, submit solutions, view feedback, and track their performance.

Project Motive

The motive of SessionalHub is to reduce manual academic workload, improve evaluation speed, support structured learning, and make assessment more efficient, scalable, and intelligent.

Created By

Created by Team Qubit Codex as an academic project to demonstrate the use of AI, OCR, NLP, database management, and role-based web application design in educational assessment.
