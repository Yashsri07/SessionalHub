# 📄 Automated Paper Generation System

An intelligent system designed to automatically generate question papers based on selected criteria such as difficulty level, units, and question types. This project aims to reduce manual effort and bring consistency, flexibility, and speed to academic paper creation.

---

## 🚀 Features

- Dynamic Question Paper Generation which Automatically creates question papers based on user inputs.

- Difficulty-Level Filtering which Generate papers with Easy, Medium, or Hard questions.

- Unit-wise Selection which Select specific units or combine multiple units for customized papers.

- Balanced Question Distribution which Ensures proper mix of questions across sections.

- Structured Output Format which Generates well-formatted papers (Section A, B, etc.)

- Fast & Efficient which Saves time compared to manual paper creation.

## ⚙️ How It Works

1. User selects:
   - Units
   - Difficulty level
   - Number of questions

2. System processes input and:
   - Filters questions from dataset
   - Applies logic for unit distribution
   - Ensures difficulty balance

3. Final output:
   - Generated question paper in structured format
